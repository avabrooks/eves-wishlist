Share to Wishlist

On your iPhone, find something in any app or website, tap Share, then tap Wishlist. The wishlist opens with it already filled in.

iPhone: Shortcut 1, works in every app

Set this up once. It goes in the Share menu of Safari, Chrome, Instagram, the Zara app and the rest.

  1. Open the Shortcuts app, tap +, and name it Wishlist.
  2. Tap the i (or the name at the top), turn on Show in Share Sheet, and under Share Sheet Types leave only URLs and Text ticked.
  3. Add the action URL Encode (search "encode"). Leave its input as Shortcut Input.
  4. Add the action Text. Tap Copy the address start below, paste it into the Text box, then tap after it and add the variable URL Encoded Text.
  5. Add the action Open URLs. Its input should be the Text from the step before.
  6. Tap Done.

iPhone: Shortcut 2, for shops that block lookups (Safari only)

Shops like Zara refuse automatic lookups. This one reads the page you're already looking at in Safari, so it works on any shop.

  1. In Shortcuts, tap + and name it Wishlist (this page).
  2. Tap the i, turn on Show in Share Sheet, and under Share Sheet Types leave only Safari web pages ticked.
  3. Add the action Run JavaScript on Web Page. Tap Copy the page reader below, then clear the sample code in the box and paste.
  4. Add the action Open URLs. Its input should be the JavaScript Result from the step before.
  5. Tap Done.

iPhone: Shortcut 3, for stubborn shops from any app (like the Google app)

Your phone downloads the page itself, the way it would if you opened it, and hands it to the wishlist to read. It works from any app's Share menu. Set it up after Shortcut 1 and try it on a Zara link.

  1. In Shortcuts, tap + and name it Wishlist (deep). Tap the i, turn on Show in Share Sheet, and leave only URLs and Text ticked.
  2. Add the action Get URLs from Input.
  3. Add the action Get Contents of URL and set its URL to the URLs variable. Tap Show More, keep the method as GET, then under Headers tap Add new header: the key is User-Agent and the value is what Copy the browser name below copies.
  4. Add a second Get Contents of URL. Tap Copy the helper address below and paste it as its URL. Tap Show More, set the method to POST and the request body to JSON. Add a Text field with the key url and the value URLs. Add another Text field with the key html and the value Contents of URL, choosing the one from the first Get Contents of URL.
  5. Add the action Open URLs. Its input should be the Contents of URL from the second Get Contents of URL.
  6. Tap Done.
